## 🎯 About the Project

The **Student Mental Health & Counseling Support System** was developed to help Sulu National High School provide organized, confidential, and accessible mental wellness support to its students. The system bridges the gap between students and school counselors through a modern, mobile-responsive platform that puts well-being first.

### Purpose

- Provide a **safe and confidential** space for students to request counseling
- Enable **counselors** to efficiently manage requests, appointments, and student records
- Give **administrators** visibility and control over the entire counseling operation
- Promote **mental health awareness** through published wellness resources
- Maintain **privacy and access control** for sensitive student information

---

## ✨ Features

### 👨‍🎓 Student Portal
- Secure registration and login
- Personal dashboard with appointment statistics
- Request counseling sessions with 60+ concern categories
- Preferred date, time, and counselor selection
- View appointment history and status in real-time
- Cancel eligible appointments
- **Private chat** with counselors
- Submit general inquiries
- Receive notifications for updates
- Browse published wellness resources
- Update profile and **upload profile picture**
- Change password securely

### 👩‍⚕️ Counselor Portal
- Comprehensive dashboard with statistics
- Manage and approve counseling requests
- Schedule, reschedule, complete, or cancel appointments
- Add confidential counseling notes
- View student profiles and history
- Publish and manage wellness resources
- Respond to student inquiries
- **Real-time chat** with students
- Generate basic reports

### 🔐 Administrator Portal
- Analytics dashboard with charts
- Manage student and counselor accounts
- Activate/deactivate user accounts
- Monitor all counseling appointments
- **Chat monitoring** for student ↔ counselor conversations
- **Direct messaging** with any student or counselor
- Manage all wellness resources (add/edit/delete)
- View all inquiries
- Generate comprehensive system reports
- Monitor system-wide statistics

### 🎨 User Experience
- Modern, calm, and professional UI
- **Light Mode** — Purple, Pink & Blue gradients
- **Dark Mode** — Red & Maroon theme
- Fully responsive (desktop, tablet, mobile)
- Smooth animations and transitions
- Accessible color contrast
- Sticky sidebar navigation

## 👥 User Roles

| Role | Description |
|------|-------------|
| **Student** | Can request counseling, chat with counselors, view resources, manage profile |
| **Counselor** | Can manage requests, appointments, students, resources, and inquiries |
| **Administrator** | Full system access including user management, reports, and chat monitoring |
